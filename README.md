# 🎨 Иллюстратор сцен NovelAI (`nai_scene_illustrator`)

Отдельное лёгкое расширение для **SillyTavern**, которое добавляет генерацию иллюстраций к любому сообщению чата через **NovelAI (V5 Medium / V5 Full / V4.5 / V3)** с поддержкой отдельной модели для составления промптов (например, GLM) и прямой передачей авторского стиля 1-в-1.

## 🚀 Как установить и настроить
1. Распакуй папку **`nai_scene_illustrator`** из архива в папку расширений SillyTavern:
   `SillyTavern/public/scripts/extensions/third-party/nai_scene_illustrator`
2. Перезагрузи страницу Таверны и открой справа **Кубики (`Extensions`) → 🎨 Иллюстратор сцен NovelAI**:
   - Вставь свой ключ NovelAI (`pst-…`) и проверь, что выбрана модель **`NovelAI V5 Medium (14 шагов — рекомендуется)`** (или `V5 Full` / `V4.5 Full`).
   - В поле **«✨ Мой стиль для NovelAI»** вставь свою строку стиля со всеми скобками `{...}`, `[...]` и весами `1.2::...::` — она приклеивается в начало каждого промпта символ в символ в обход текстовой модели.
   - В блоке **«🧠 Какая модель пишет промпты для картинок»** можно оставить основную модель чата, выбрать готовый профиль Таверны (например, GLM) или подключить свой API по ключу.

## 🎬 Как пользоваться в чате
- Нажми иконку картинки **`🖼`** в правом верхнем углу любого сообщения чата и выбери ракурс (*Взгляд со стороны со всеми участниками сцены*, *POV с рукой в кадре* или *Чистый взгляд напротив*).
- Картинка появится **отдельным блоком прямо под текстом поста** (не перекрывая текст).
- Прямо под картинкой расположена панель **`◀` · `Вариант X / N` · `+ Ещё ▶`**:
  - Нажатие на правую стрелку **`▶`** сразу рисует ещё один вариант картинки по тому же самому промпту (без повторного обращения к текстовой модели).
  - Нажатие на **`Вариант X / N`** раскрывает текстовое поле с промптом, где можно вручную подправить теги перед нажатием **`▶`**.
